# Reproducibility

Every headline numerical macro in the paper resolves back to a
producing script and a measurement JSON in this repository. This
file is the index.

## How the paper macros are wired

The paper's `shared/macros.tex` ships with the submission
snapshot of every `\newcommand`. The values were generated by the
scripts under [`scripts/`](scripts/) and persisted under
[`data/provenance/`](data/provenance/) and
[`models/`](models/). To regenerate any macro from scratch,
re-run the script (which rewrites the corresponding
`summary.json` / `nested_kfold_summary.json` / `results.json`),
then re-build the paper.

## How to reproduce

> **Note**: Raw KuniJiban boring records cannot be redistributed
> under KuniJiban's terms of use. To reproduce the headline
> numbers, first obtain the same XML records from
> <https://www.kunijiban.pwri.go.jp/> following the extraction
> procedure in
> [`supplementary/S1_provenance_log_spec.pdf`](supplementary/S1_provenance_log_spec.pdf),
> then point this repository's scripts at your local extract.

```bash
# 1. Install (Python 3.12 recommended)
python -m venv .venv
source .venv/bin/activate
pip install -e .[baselines]

# 2. Configure the path to your local KuniJiban extract
cp .env.template .env
# Edit .env to set KUNIJIBAN_DATA_DIR

# 3. Preprocess KuniJiban into the Kanto modelling Parquet
python -m scripts.prepare_training_data --region kanto

# 4. Generate canonical spatial-K-fold mesh assignments
python -m scripts.make_fold_indices --K 3 --seed 42
# writes data/fold_indices/kanto_{random,contig}_K3_*.csv

# 5. Train the DKL+SVGP operational model (released foundation model)
python -m scripts.train_kanto_smoke \
    --parquet data/features/borings_kanto_aist.parquet \
    --output-dir data/runs/kanto_full_6k_50ep_linear_rbf \
    --kernel rbf --mean linear --n-inducing 6000 \
    --n-epochs 50 --batch-size 4096 --lr 5e-3 --regime-one-hot

# 6. Train tree-ensemble + GPBoost + CQR baselines
python -m scripts.run_baselines           # CatBoost / LightGBM / XGBoost / HGB
python -m scripts.train_gpboost           # Vecchia-approximated GP
python -m scripts.train_lightgbm_cqr      # CQR-LightGBM

# 7. Proper K-fold evaluation + fair Table 6 (paired BCa CI for GPBoost win)
python -m scripts.compute_tree_conformal_paired_bca

# 8. Conformal calibration + Mondrian decomposition
python -m scripts.compute_locally_weighted_conformal

# 9. Buffered CV + leave-prefecture-out (DKL+SVGP envelope)
python -m scripts.eval_buffered_cv --geometry random
python -m scripts.eval_buffered_cv --geometry contig
python -m scripts.eval_leave_prefecture

# 10. Right-censored survival reformulation (Schoenfeld → RSF released)
python -m scripts.train_survival_cox_ph
python -m scripts.train_survival_weibull_aft
python -m scripts.train_survival_rsf

# 11. Threshold classifiers + hurdle + cross-fit hybrid
python -m scripts.run_threshold_classifiers
python -m scripts.train_hurdle_model
python -m scripts.train_hybrid_kanto --inner-k 5

# 12. Regional screening outputs + paper figures/tables
python -m scripts.build_paper_figures
python -m scripts.build_paper_tables
```

After step (12), every macro in `shared/macros.tex` is
re-derivable from this repository.

## What is and isn't in this archive

**Included**:

- Source code (Python package `national/` + CLI scripts under
  `scripts/`) for all model training, evaluation, calibration,
  and release-artefact generation across the framework's six
  candidate regressors, three survival predictors, conformal
  layer, threshold classifiers, hurdle, and cross-fit hybrid.
- Canonical spatial K-fold mesh-assignment CSVs for random,
  contiguous, buffered, and leave-prefecture-out geometries.
- Per-run `summary.json` / `nested_kfold_summary.json` /
  `results.json` provenance logs.
- Trained model checkpoints (via GitHub Release asset; see
  [README](README.md#large-artefacts)).
- Conformal calibration outputs (marginal `q_α` + per-bin
  Mondrian `q_α^(c)` quantiles).
- Regional raw-N threshold-exceedance maps (Cloud-Optimised
  GeoTIFF slices for P(N<c) and P(N≥30)) plus the
  > 5 km nearest-borehole do-not-trust mask.
- Site-scale per-borehole depth profiles at five representative
  Kanto locations.
- Supplementary Material S1 (provenance log specification) and
  S2 (evaluation module specification).

**Not included**:

- Raw KuniJiban borehole XML records — cannot be redistributed
  under KuniJiban's terms of use. The pipeline is layout-stable
  across KuniJiban revisions; readers can obtain their own
  extract and reproduce all results.
- The upstream development repository, which carries the
  national-scale prediction service, the frontend, additional
  experiment logs, and follow-up work that may evolve beyond the
  paper's scope. That code lives at
  <https://github.com/UT-Team-Chun/geo-estimation>; the present
  repository is the canonical reference for the submitted
  manuscript.
